<p><b>Miniflux</b> est un agrégateur de flux <a href="https://fr.wikipedia.org/wiki/RSS" title="RSS" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">RSS</a> minimaliste. C&#39;est une <a href="https://fr.wikipedia.org/wiki/Application_web" title="Application web" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">application web</a> <a href="https://fr.wikipedia.org/wiki/Logiciel_libre" title="Logiciel libre" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">libre</a> diffusé sous licence <a href="https://fr.wikipedia.org/wiki/AGPL" title="AGPL" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">AGPL</a>.
Ce logiciel est prévu pour être <a href="https://fr.wikipedia.org/wiki/Auto-h%C3%A9bergement_(Internet)" title="Auto-hébergement (Internet)" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">auto-hébergé</a> sur son propre serveur ou sur un hébergement mutualisé.
</p>
<h2>Caractéristiques[<a href="https://fr.wikipedia.org/w/index.php?title=Miniflux&amp;veaction=edit&amp;section=1" title="Modifier la section : Caractéristiques" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">modifier</a> | <a href="https://fr.wikipedia.org/w/index.php?title=Miniflux&amp;action=edit&amp;section=1" title="Modifier le code source de la section : Caractéristiques" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">modifier le code</a>]</h2>
<ul><li>Mises à jour : il est possible de mettre à jour ses abonnements depuis une tâche planifiée (<a href="https://fr.wikipedia.org/wiki/Cron" title="Cron" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">cronjob</a>) ou depuis l&#39;interface web (<a href="https://fr.wikipedia.org/wiki/Ajax_(informatique)" title="Ajax (informatique)" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">Ajax</a>). De plus, Miniflux vérifie les en-têtes <a href="https://fr.wikipedia.org/wiki/HTTP" title="HTTP" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">HTTP</a> et met à jour les flux uniquement lorsque c&#39;est nécessaire.</li>
<li>Réseaux sociaux : Miniflux ne s&#39;intègre pas avec les réseaux sociaux, il n&#39;y a donc aucune forme de partage, d&#39;envoi par email ou encore de système de favoris.</li>
<li>Publicité : les publicités dans les abonnements sont supprimées automatiquement ainsi que tout éventuel &#34;<a href="https://fr.wikipedia.org/wiki/Pixel_espion" title="Pixel espion" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">pixel espion</a>&#34; (image de 1px sur 1px utilisée par les outils de statistiques). De plus, les liens externes ne transmettent pas le <a href="https://fr.wikipedia.org/wiki/R%C3%A9f%C3%A9rent_(informatique)" title="Référent (informatique)" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">référent</a> (l&#39;<a href="https://fr.wikipedia.org/wiki/Uniform_Resource_Locator" title="Uniform Resource Locator" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">adresse web</a> d&#39;où l&#39;utilisateur vient).</li>
<li>Données personnelles : Miniflux est compatible avec le format <a href="https://fr.wikipedia.org/wiki/OPML" title="OPML" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">OPML</a> qui permet d&#39;importer ou d&#39;exporter sa liste d&#39;abonnements.</li>
<li>Accessibilité : une fois installé, Miniflux est accessible à la manière d&#39;une <a href="https://fr.wikipedia.org/wiki/Application_web" title="Application web" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">application web</a> depuis n&#39;importe quel navigateur web et ce même sur les appareils mobiles.</li>
<li><a href="https://fr.wikipedia.org/wiki/Interface_de_programmation" title="Interface de programmation" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">Interface de programmation</a>: Le logiciel intègre une interface de programmation de sorte à voir créer des scripts afin d&#39;automatiser certaines tâches comme la création d&#39;un utilisateur, de récupérer des statistiques ou encore de récupérer des données concernant son flux ou ses abonnements<sup id="cite_ref-2"><a href="#cite_note-2">[2]</a></sup>.</li></ul>
