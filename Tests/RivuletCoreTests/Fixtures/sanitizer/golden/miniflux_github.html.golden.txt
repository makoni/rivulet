<li>Works only with Postgresql</li>
<li>Doesn&#39;t use any ORM</li>
<li>Doesn&#39;t use any complicated framework</li>
<li>Use only modern vanilla Javascript (ES6 and Fetch API)</li>
<li>Single binary compiled statically without dependency</li>
<li>The number of features is voluntarily limited</li>
</ul>
<p>It&#39;s simple, fast, lightweight and super easy to install.</p>
<p>Official website: <a href="https://miniflux.app" rel="noopener noreferrer" referrerpolicy="no-referrer" target="_blank">https://miniflux.app</a></p>
